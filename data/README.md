# Dataset

Simpan dataset asli sebagai `full_articles.csv`. Skrip preprocessing mendeteksi judul, ID, abstrak Bahasa Indonesia, fallback abstrak Inggris, dan kata kunci.

Periksa izin penggunaan/redistribusi dataset di sumber asal dan cantumkan sitasinya. Jangan commit dataset besar ke repository publik tanpa memeriksa lisensi.
